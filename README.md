Resumen del Proyecto
Esta es una aplicación de gestión para un inventario de repuestos. La desarrollé usando Node.js, Express y una base de datos en MongoDB para que toda la información se guarde correctamente.

¿Qué incluí en el trabajo?
Estructura MVC: Organicé el código en carpetas de modelos, rutas y vistas para que sea fácil de entender y mantener.

Base de Datos: Usé Mongoose para crear el esquema de los productos y conectar el servidor con MongoDB.

Subida de Archivos: Implementé Multer para que el sistema permita subir fotos de los repuestos y las guarde en la carpeta uploads.

Chat en Vivo: Puse un módulo de chat con Socket.io para que haya comunicación en tiempo real entre los usuarios.

Pasos para ejecutar:
Descargar el proyecto y abrir la carpeta en la terminal.

Escribir npm install para que se bajen todas las librerías necesarias.

Tener MongoDB Compass activo.

Lanzar el proyecto con el comando: node app.js.

Entrar al navegador en: http://localhost:3000.
